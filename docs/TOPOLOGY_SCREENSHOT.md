# Снимок топологии NetLab

В открытой лаборатории нажмите кнопку **Снимок** (сразу после «Остановить»). Браузер скачает PNG с названием `NetLab_<название>_YYYY-MM-DD.png`. В некоторых браузерах потребуется разрешить скачивание.

Экспорт включает **всю** топологию независимо от её масштаба и положения на экране: устройства, подписи, значки из `/icons`, кабели и имена портов, текстовые примечания с цветами. Все элементы отрисовываются Canvas API локально в браузере. Сервер не получает и не сохраняет экспортный файл.

Это не снимок диска QEMU и не сохранение состояния виртуальной машины. Для сохранения конфигурации используйте штатные средства сетевой ОС и резервную копию данных NetLab.

Рендерер находится в `web/topology-snapshot.mjs`, не использует внешние JavaScript библиотеки или удалённые сервисы. Для больших топологий разрешение автоматически ограничивается. Если конкретная иконка не загрузилась, вместо неё отображается резервный символ устройства.
