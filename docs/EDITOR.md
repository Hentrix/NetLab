# Редактор топологии NetLab 0.6.2

Рабочее поле содержит собственную плавающую панель инструментов (слева сверху) и панель масштаба (слева снизу).

## Действия

| Инструмент | Клавиша | Действие |
| --- | --- | --- |
| Выбор | V | ЛКМ по устройству, перенос; Ctrl/Shift+ЛКМ для выбора нескольких |
| Рука | H / пробел | Панорамирование с помощью перетаскивания |
| Кабель | C | Выбор двух устройств; или протягивание за значок цепи на устройстве |
| Рамка | M | Перетаскивание рамки вокруг нескольких узлов |
| Текст | T | Щелчок по полю → ввод текста в диалоге → сохранение |
| Примечание | N | Протягивание области → ввод текста → сохранение |
| Плюс | + (кнопка) | Создание узла через шаблон |

По примечанию: двойной щелчок для редактирования, ПКМ для удаления; его также можно перетаскивать.

## Порты и скорости

Для существующих устройств без `ports` визуальные обозначения вычисляются по `portStyle` и профилю сетевой карты.
Каждый порт имеет собственный необязательный descriptor `{name, speedMbps}` с возможностью изменения на запущенной виртуальной машине.
Пустое `name` означает автоматическое имя; `speedMbps:0` означает значение модели NIC по умолчанию.
В модели Cisco выбирается Fa/Gi/Te (100 / 1000 / 10000 Мбит/с и выше). В RouterOS используется etherN, поскольку имена не зависят от скорости.

**Важное ограничение:** скорость — метаданные сетевой схемы. Обновление `ports[]` не изменяет скорость Ethernet внутри гостевой ОС и не применяет `tc`/QoS на TAP.
Индекс `aPort/bPort` кабеля остаётся индексом NIC QEMU, поэтому редактирование подписи безопасно при горячей коммутации.

## Параллельные кабели

Кабели группируются по неупорядоченной паре устройств, сортируются по индексам портов и получают разные точки выхода на торце значка.
Направление A/B в JSON не влияет на порядок размещения. Подписи рисуются у соответствующего конца каждого кабеля.
При большом числе кабелей расстояние между точками уменьшается, чтобы все точки помещались на иконке.

## Хранение

У каждой лаборатории теперь есть необязательный массив `annotations`; у узлов — `ports`.
API: `POST /api/labs/:lab/annotations`, `PATCH/DELETE /api/labs/:lab/annotations/:id`; изменение метаданных портов через `PATCH /api/labs/:lab/nodes/:id`.
Все операции требуют текущего Bearer-токена, проверяются сервером и сохраняются в `/var/lib/netlab/state.json`.

## Текст и примечания: поведение при уменьшении

- Минимум для примечания: 144×58 px; для текста: 96×36 px. Минимальная высота может быть больше при нескольких строках.
- При уменьшении доступной области отображаемый шрифт автоматически уменьшается до 11 px; выбранный в оформлении размер остаётся прежним и возвращается при увеличении блока.
- Если содержимое всё равно длиннее максимально допустимой области, появляется внутренняя прокрутка. Колесо мыши над таким текстом не масштабирует полотно.
- ПКМ по аннотации → «Подогнать высоту под текст» увеличивает высоту и сохраняет изменение.
- Цвет текста, заливки и рамки выбирается прямо у соответствующей подписи.
